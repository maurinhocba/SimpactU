📋 ESTRATEGIAS DISPONIBLES EN SIMPACT:
  • EXPLCT  → Integración temporal EXPLÍCITA (explicit time integration)
             - Calculos paso a paso sin matriz global
             - Menor costo computacional por paso
             - Requiere paso temporal pequeño para estabilidad
  
  • IMPLICIT → Integración temporal IMPLÍCITA
               - Resuelve sistema lineal cada paso
               - Permite paso temporal más grande
               - Mayor costo pero más estable
  
  • WIND    → Análisis de cargas wind-only (sin acoplamiento estructural)

RESUMEN DE LA PARTE 2-A:
--------------------------------------------------------------------------------

✅ LO QUE OCURRE EN ESTE BLOQUE:
   1. Entramos en bucle sobre estrategias numéricas disponibles
   2. Seleccionamos la estrategia activa mediante ptype (EXPLCT, IMPLICIT, etc.)
   3. Para EXPLCT + problema NUEVO/NSTRA0:
      - Llamamos a data_inp() para leer datos de entrada
      - Configuramos control aeroelástico con contol(actio)
      - Si es nuevo y aero: cargamos aerodinámica (aero_data)
      - Leemos simulación (Input_simulation), extras (Input_extras)
      - Definimos geometría (Input_geometry)
      - Reservamos memoria con Alloc() usando info de Input_simulation
      - Si modelo SHELL: leemos datos BED (Input_bed)

⚠️ PUNTO CRÍTICO A ENTENDER:
   • ptype determina QUÉ estrategia numérica usar (EXPLCT, IMPLICIT, WIND)
   • actio controla QUÉ tipo de problema (NEW, NSTRA0, RESTAR)
   • La combinación de ambos dicta qué funciones se llaman
   • Para EXPLCT + NEW: carga completa de datos aerodinámicos y memoria

📝 NOTAS IMPORTANTES:
   • Las llamadas rdwind(), rdctrl(), gener_inp() están comentadas (no usadas)
   • Alloc() depende críticamente de INPUT_SIMULATION para reservar memoria correcta
   • El modelo SHELL requiere datos BED adicionales para geometría detallada
