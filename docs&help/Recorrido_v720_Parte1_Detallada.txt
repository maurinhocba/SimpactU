LÍNEAS ORIGINALES 5-19: PARÁMETRO "actio" - TIPO DE PROBLEMA

% actio = parámetro que indica QUÉ tipo de problema vamos a resolver
% Se asigna en la función beginp (beginning of problem)

📊 VALORES POSIBLES DE "actio":
  • NEW     → Nuevo problema (primera vez que se ejecuta)
  • RESTAR  → Reiniciar problema antiguo (sin cambios o cambios menores)
  • NSTRA0  → Reiniciar con nueva estrategia (mismo problema, diferente método)
            (puede ocurrir en la misma ejecución de Simpact)
  
% Posibles extensiones futuras:
  • NSTRA1  → Nueva estrategia cambiando condiciones de contorno (sin cambiar nodos)
  • NSTRA2  → Nueva estrategia cambiando nodos Y condiciones de contorno
  • STOP    → Detener el programa
  • MESHMO  → Modificaciones de malla en el paso temporal

% En la versión aeroelástica actual se usan: NEW, RESTAR, NSTRA0 o STOP

📝 DETALLE DE CADA FUNCIÓN "restar_*":
  • restar_structuresa    → Reinicia datos de estructura aerodinámica (masas, rigidez, modos)
  • restar_arraysa        → Reinicia arrays de almacenamiento aeroelástico (matrices, vectores)
  • restar_aeroout        → Reinicia archivos de salida aerodinámica (fuerzas, presiones)
  • restar_win            → Reinicia ventanas de visualización o interfaz gráfica
  • restar_inter          → Reinicia módulo de acoplamiento fluido-estructura (FSI)
  • restar_introut        → Reinicia módulos de entrada/salida internos del solver
  • restar_struout       → Reinicia salida de datos estructurales (desplazamientos, tensiones)

LÍNEAS ORIGINALES 42-43: INICIO DEL BUCLE SOBRE ESTRATEGIAS
--------------------------------------------------------------------------------

DO % endless over strategies
  │
  ├─→ Este bucle recorre TODAS las estrategias de cálculo aeroelástico
  │   disponibles en el solver (por ejemplo: EXPLCT, IMPLICIT, WIND)
  │
  ├─→ Dentro del bucle se selecciona la estrategia activa mediante ptype
  │
  └─→ Se inicializa los datos específicos de esa estrategia

📋 ESTRATEGIAS TÍPICAS EN SIMPACT:
  • EXPLCT  → Integración temporal explícita (calculos paso a paso, sin matriz global)
  • IMPLICIT → Integración implícita (resuelve sistema lineal cada paso)
  • WIND    → Análisis de cargas wind-only (sin acoplamiento estructural)

RESUMEN DE LA PARTE 1:
--------------------------------------------------------------------------------

✅ LO QUE OCURRE EN ESTE FLUJO INICIAL:
   1. Detectamos qué tipo de problema es (NEW, RESTAR o NSTRA0)
   2. Si es reinicio (RESTAR/NSTRA0), llamamos a funciones específicas para
      reiniciar cada módulo del solver
   3. Abrimos archivos de entrada/salida y escribencabezados si es nuevo
   4. Entramos en bucle sobre estrategias para procesar cada una

⚠️ PUNTO CRÍTICO A ENTENDER:
   • "actio" determina el flujo de inicialización
   • "restar_*" son funciones de reinicio que limpian y re-inician cada módulo
   • El bucle sobre estrategias permite ejecutar múltiples métodos en una sola simulación
