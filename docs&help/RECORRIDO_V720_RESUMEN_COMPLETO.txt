PUNTOS CRÍTICOS DE LA SIMULACIÓN AEROELÁSTICA V720:
================================================================================

1. CALL dynamic() es el CORAZÓN de toda la simulación aeroelástica dinámica
2. El bucle temporal interno (while) realiza la integración numérica paso a paso
3. La matriz A representa el sistema aeroelástico completo con acoplamiento fluido-estructura
4. wake_mgmt() mantiene la estela para cálculos aerodinámicos precisos
5. airfoil_tab() proporciona coeficientes aerodinámicos no lineales
6. Los criterios de terminación (endst, convergencia) controlan cuándo finalizar
7. CALL byebye(time) es esencial para limpieza de recursos y cierre correcto
