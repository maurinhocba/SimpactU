LÍNEAS 112-113: CONSTRUCCIÓN Y RESOLUCIÓN DEL SISTEMA LINEAL AEROELÁSTICO
--------------------------------------------------------------------------------

CALL A_matrix() [CONSTRUCCIÓN DE LA MATRIZ AEROELÁSTICA GLOBAL]
│   │
│   ├─→ Construye matriz completa del sistema aeroelástico acoplado
│   ├─→ Formato: A*G = RHS (sistema lineal implícito)
│   ├─→ Matriz A incluye:
│   │    • Contribuciones de rigidez estructural (K_structural)
│   │    • Contribuciones aeroelásticas no-lineales (A_aerodynamic)
│   │    • Acoplamiento fluido-estructura (coupling terms)
│   ├─→ Grados de libertad en matriz A:
│   │    • Desplazamientos estructurales (u, v, w)
│   │    • Presiones aerodinámicas o coeficientes de presión
│   │    • Coordenadas de estela (si aplica)
│   └─→ RHS contiene:
│       • Cargas externas (presión dinámica, gravedad)
│       • Contribuciones aeroelásticas no-lineales
│       • Términos de acoplamiento FSI

CALL DGESV() [RESOLUCIÓN DEL SISTEMA LINEAL]
│   │
│   ├─→ Resuelve sistema lineal A*G = RHS usando algoritmo Gauss-Seidel o similar
│   ├─→ G contiene:
│   │    • Desplazamientos estructurales en cada nodo (u, v, w)
│   │    • Variables aerodinámicas (coeficientes de presión, fuerzas locales)
│   │    • Posiciones de nodos de estela
│   └─→ Resultado: posiciones actualizadas de todos los nodos
        • Estructurales: nuevos desplazamientos según cargas aerodinámicas
        • Aerodinámicos: nuevas configuraciones según deformación estructural

┌─→ 🎯 IMPORTANCIA DE DGESV():
│     Esta es la parte MÁS CRÍTICA del bucle temporal!
│     
│     ALGORITMO USADO: Gauss-Seidel iterativo o similar para resolver A*G=RHS
│     
│     ¿POR QUÉ ES TAN IMPORTANTE?
│       • Resuelve el sistema aeroelástico ACOPLANO estructura-aerodinámica
│       • Obtiene desplazamientos estructurales (u,v,w) según cargas aerodinámicas
│       • Determina nuevas configuraciones geométricas para siguiente iteración
│       • Sin esta resolución = NO HAY RESPUESTA ESTRUCTURAL a cargas aerodinámicas
│     
│     📌 GRADOS DE LIBERTIDAD EN LA MATRIZ A:
│        - Desplazamientos estructurales (u, v, w) en cada nodo
│        - Presiones aerodinámicas o coeficientes de presión locales  
│        - Posiciones de nodos de estela (si aplica)
│     
│     📌 LO QUE CONTIENE EL VECTOR G (SOLUCIÓN):
│        - Desplazamientos estructurales en cada nodo
│        - Variables aerodinámicas (coeficientes de presión, fuerzas locales)
│        - Posiciones actualizadas de nodos de estela

✅ LO QUE OCURRE EN CADA PASO TEMPORAL:
   1. Verificamos si es nueva etapa aeroelástica (resetear o continuar)
   2. Actualizamos coordenadas de interfaz FSI (inter_kin)
   3. Calculamos fuerzas aerodinámicas en Control Points (NLUVLM_Calc)
   4. Construimos vectores RHS1 y RHS2 (fuerzas externas + estela)
   5. Visualizamos mallas en TecPlot (opcional)
   6. Construimos matriz aeroelástica global A_matrix()
   7. Resolvemos sistema lineal DGESV() para obtener desplazamientos
   8. Calculamos propiedades de segmentos de estela (Segment_properties)
   9. Calculamos cargas aerodinámicas totales (Loads)
   10. Ajustamos paso temporal dinámicamente (DtCalc + incdlt)
   11. Transportamos estela convectivamente (Convect)
   12. Post-procesamiento de fuerzas y momentos
   13. Actualizamos contadores y tiempo simulado
   14. Si necesario: integración temporal explícita (comentada)
   15. Dumping de archivos si alcanzamos criterios de parada

🎯 ¿QUÉ OCURRE EN CADA PASO TEMPORAL?
-----------------------------------------
Este bucle representa el "CORAZÓN DEL CÁLCULO" aeroelástico donde ocurre todo
el acoplamiento fluido-estructura dinámico. Cada iteración es un instante físico
real donde:

1. La aspa se ha deformado según cargas aerodinámicas anteriores
2. Las nuevas configuraciones geométricas generan nuevos ángulos de ataque
3. Los coeficientes aerodinámicos CL(α), CD(α) cambian dinámicamente
4. Las fuerzas aerodinámicas se recalculan con nueva geometría
5. El ciclo se repite hasta convergencia o fin del paso temporal

🔑 PUNTOS CRÍTICOS IDENTIFICADOS:
-----------------------------------------

1. DGESV() - LA FUNCIÓN MÁS IMPORTANTE:
   • Resuelve el sistema aeroelástico acoplado A*G = RHS
   • Obtiene desplazamientos estructurales (u,v,w) en cada nodo
   • Sin esta resolución = NO HAY RESPUESTA ESTRUCTURAL

2. Segment_properties() + Convect():
   • Manejan la estela transportada por el flujo
   • Representan el historial de vorticidad que afecta fuerzas actuales
   • Cruciales para calcular fuerzas aerodinámicas correctas

3. Loads():
   • Integra presiones sobre paneles tras solución DGESV()
   • Proporciona cargas totales para evaluar desempeño estructural/aerodinámico

4. DtCalc(.TRUE.) + incdlt():
   • Ajustan paso temporal dinámicamente según convergencia observada
   • Mantienen estabilidad numérica del cálculo aeroelástico

📁 ARCHIVOS DE SALIDA GENERADOS:
-----------------------------------------
• root.AR.dat - Registro aeroelástico (incluye tabla de dtime)
• root.FM.dat - Fuerzas y momentos totales por aspa
• root.AT.dat - Tiempo transcurrido en cálculos aeroelásticos
• TecPlot outputs (.lay, .plt) - Visualización de mallas y fuerzas

⚠️ PUNTO DE ATENCIÓN:
-----------------------------------------
La llamada DGESV() es el paso más crítico porque resuelve todo el sistema
aeroelástico acoplado. Sin una resolución correcta, toda la simulación pierde
física aeroelástica válida.
