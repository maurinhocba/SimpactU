# SimpactU
Intended to embed Martín Perez Segura's UVLM_2.0 into Fernando G. Flores' Simpact.

## Uso de branches:
- main: versión probada, lista para usar por cualquiera, solo recibe cambios desde develop - branch permanente
- develop: paso previo a mail, últimas verificaciones, todos los desarrollos se hacen en otros branches que contribuyen a develop - branch permanente
- UVLM_2.0: versión actualizada del código aerodinámico listo para funcionar standalone (podría cambiar en adelante si hay mejoras o ampliaciones, más probablemente de Martín Perez Segura o de Santiago Ribero) - no sabemos si va a aportar a develop, dependerá de si lo podemos incorporar tal cual está en Simpact o si necesitamos hacerle cambios - branch permanente
- UVLM/first-comp: branch de duración finita, hasta que ande la primera compilación - aporta a UVLM_2.0
- SimpactA: versión actualizada del código aeroelástico que venimos usando listo para funcionar standalone (podría cambiar en adelante si hay mejoras o ampliaciones, del grupo de trabajo o de Fernando Flores) - será el primer insumo para develop, luego no sé - branch permanente
